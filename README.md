# Exploratory and Reporting Project

An exploratory data analysis and reporting project focused on analyzing data and generating business insights.

## Prerequisites

Before running any code in this repository, initialize the database using one of the following options:

1. Restore the `DataWarehouseAnalytics.bak` database backup file located in the `datasets` folder.
2. Run the database initialization scripts available in my other repository, [`sql-data-warehouse-project`].
